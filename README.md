# My Tamil Cinema (Legal Demo) — Stremio addon

This is a starter Stremio addon with a small movie catalog, metadata, and one direct demo stream from the Blender Foundation's Big Buck Bunny sample video.

It does **not** connect to Moviesda or scrape copyrighted movies. Add only titles and stream URLs you own, have licensed, or are legally authorized to distribute.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm start
```

Then open `http://127.0.0.1:7000/manifest.json` in Stremio on the same network.

## Deploy on Render

1. Create a Render Blueprint and connect this GitHub repository.
2. Render reads `render.yaml` and deploys the service.
3. After deployment, test `https://YOUR-SERVICE.onrender.com/manifest.json`.
4. Install that HTTPS manifest URL in Stremio.

The public manifest URL is generated by Render after deployment.

## Add authorized titles

Edit `demoMovie` in `addon.js` and add only metadata and stream URLs you own, have licensed, or are legally authorized to distribute.

A free hosting plan may sleep when idle, depending on provider rules.
